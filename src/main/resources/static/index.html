  1. 准备数据录入真实发票与差旅，或加载注明为 DEMO 的示例数据。
  2. 发起 Agent 任务通过自然语言描述出差日期、城市和报销目标。
  3. 处理流程节点缺件时补充材料，政策冲突时审批，最后确认提交。
